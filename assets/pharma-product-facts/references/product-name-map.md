## 维护约定

- **本表是仓库静态制品，只经 git（人工提交）维护——运行时 skill 一律不得 `skill_manage`/`patch`
  改写它。** 某产品通用名经本轮适配官方来源核验后，**仅用于当轮作答**；**勿回写本表**部署副本
  （避免部署偏离包内静态资源并污染后续评测）。如需沉淀，另写
  `${HERMES_HOME}/workspace/pharma-product-facts/` 笔记或 memory，不改本 skill 文件。
- 若要正式更新本表（去「疑似」或补通用名），走**开发仓 git 改动 + 复跑测试**，并在评审记录中保留
  实际采用的公开来源；不在用户部署侧运行时改。得佑/天韵/甘美/甘平 的通用名于 2026-07-24 由
  问答语料 + PubMed 佐证补入，仅作为身份候选，不代表任何产品标签事实已经核验。
- 本表**不承载适应症/剂量/规格等事实**——那些永远从说明书 PDF 现取现引，不写进本表。
